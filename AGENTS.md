# Syre Banks Fitness repository workflow

The `main` branch of `https://github.com/SyreCodes/SyreBanksFitness.git` is the source of truth. GitHub Actions checks pushes and pull requests to `main`. Azure hosts the app in South Africa North. Hosted login, media and worker checks passed on 24 October 2026. Registry metadata Reader access was explicitly approved and assigned. The public domain is https://ubuntustar.com; custom-domain login and runtime recovery passed on 25 October 2026. Production releases are enabled after quality gates; verify the exact GitHub release result before claiming a commit deployed. Local edits alone never update a hosted app. Follow docs/AZURE_DEPLOYMENT.md for deployment prerequisites and verified status; distinguish a passing source check from a successful Azure release. Do not import local/demo data or run the production seed; email delivery is deliberately deferred.

For completed changes intended for GitHub, run the relevant local quality checks, commit the task's source changes, and push to `origin main` so CI can check them. Do not push failing or incomplete changes. Follow any newer user request for a review, branch, PR, or local-only work instead. Never commit `.env`, credentials, local databases, or uploaded media.

When changing the database, keep migrations compatible with the previous API and worker release because future services may roll out separately. Once hosting is configured, validate login, `/ready`, and the changed user flow after deployment.
